# 气象驱动用电负荷预测与高峰备电

检索关键词：load_mw、用电负荷、气温、热浪、寒潮、晚高峰、空调负荷、采暖负荷、备电。
依据公开资料整理：《电力现货市场基本规则（试行）》关于运行日分时段负荷预测、母线负荷预测及可靠性机组组合边界的规定，以及气象–负荷领域通行机制。本文为检索摘要。本系统不下单。

## 气温–负荷机制

用电负荷 load_mw 对气温高度敏感。华东等夏季空调负荷地区：日最高气温超过约 33℃（热浪 is_heat_wave=1）后，负荷随气温近似加速上升，晚高峰（17–21 时）最显著。冬季寒潮（is_cold_wave=1）抬升采暖负荷，早高峰和夜间低谷都会上移。

湿度、人体舒适度也会影响空调用电；单纯看 temp_c 均值可能低估极端日。weekday、hour、is_weekend 用于捕捉工作日/周末和日内形状，应与气象特征一起解释，不要只谈算法。

## 调度用途

电力调度机构在经营主体申报前开展运行日分时段负荷预测和母线负荷预测。可靠性机组组合根据发电侧报价、可再生能源出力预测、省间送受电和系统负荷预测，确定启停。负荷预测偏差会直接变成机组组合偏差：偏低则实时顶峰不足、电价上冲；偏高则机组多开、新能源消纳空间被挤占。

晚高峰备电：热浪日空调负荷叠加居民归家，净负荷高峰常出现在傍晚光伏已落、风电不确定的窗口。训练报告若看到 hour、temp_c、is_heat_wave 重要性靠前，应点明「晚高峰备电」而不是笼统「负荷会涨」。

## 极端情景清单

- 热浪：持续高温、负荷创新高、备用紧张、现货高价。
- 寒潮：取暖负荷升，若风光同时偏低，残余负荷更高。
- 台风：部分工业负荷停产下降，同时风电切出、光伏受阴雨抑制，净效应要分时段看，禁止只写「台风一定让负荷下降」。
- 节假日：hour/weekday 特征主导，气象敏感性下降。

## 偏差考核注意

用户侧、售电公司和代理购电的偏差电量常按现货价格结算。负荷预测系统性偏低，购电侧可能在实时高价补电。本平台 load_mw 模型是气象驱动回归，RMSE 反映拟合误差，不是售电公司考核账单。

预测出现不合理负值应检查数据；负荷物理上不应为负。

## 对 LLM 报告的约束

解读用电负荷训练任务时，把气温、热浪/寒潮与晚高峰备电写成因果链，引用本轮 RMSE/MAE/R²。涉及顶峰、错峰、需求响应或购电策略，必须写需人工确认。
