# 风光合计出力、残余负荷与反调峰

检索关键词：renewable_mw、风光出力、风光合计、残余负荷、反调峰、新能源高发、消纳、电价承压。
依据公开资料整理：《电力现货市场基本规则（试行）》中可再生能源出力预测作为机组组合与现货出清边界的规定，以及调度运行中「净负荷 / 残余负荷」通行口径。本文为检索摘要。本系统不下单。

## 定义

风光合计出力 renewable_mw ≈ wind_mw + solar_mw（若系统中另有独立预测，以模型目标列为准）。残余负荷 residual_mw ≈ 系统用电负荷 load_mw − 新能源出力。现货价格和火电调峰压力主要跟随残余负荷，而不是单独某一类电源。

新能源高发时段（午间光伏高峰、夜间或冷空气过境时的风电高峰）残余负荷被挤压，现货价格易走弱；若同时断面阻塞，出现消纳受阻和负电价或低价。新能源低发叠加负荷高峰，残余负荷抬升，价格易涨。

## 反调峰

光伏白天高、夜间近 0，负荷却常在早晚高峰。风电也常夜间高发。于是净负荷曲线可能「白天低、早晚高」，火电需要更深调峰，这就是反调峰。风光合计模型若拟合良好，可帮助判断次日净负荷低谷出现在何时。

对交易与调度的含义：

- 新能源高发 + 负荷不高：减少顶格申报发电，关注限电与低价。
- 新能源低发 + 晚高峰负荷：备电、顶峰与向上价格风险。
- 只看 renewable_mw 均值会掩盖午间尖峰和夜间风电，报告应结合时段形态。

## 与分项模型的关系

wind_mw、solar_mw 分开训练再相加，与直接训练 renewable_mw，误差结构不同：分项误差可能部分对冲，也可能在同向极端天气下叠加。热浪：光伏升、负荷升、风电不一定升。台风：风电先升后切出、光伏受云雨抑制、负荷视登陆路径。寒潮：负荷升、风光不确定。

特征重要性若同时出现辐照、风速和气温，说明模型在学「气象–新能源–净负荷」耦合，而不是单点相关。

## 偏差与消纳

日前市场以新能源预测为边界。若风光合计预测偏高，机组组合可能少开火电，实时新能源不足时需高价调用，偏差结算对系统不利。若预测偏低，可能多开火电、新能源被迫限电，出现消纳受阻。

负出力应裁剪为 0。限电时段的实际 renewable_mw 低于资源可用值，不能简单当成预测失败。

## 对 LLM 报告的约束

解读风光合计训练任务时，用 RMSE/MAE/R² 说明拟合，用特征重要性说明「高发挤压残余负荷」是否学到。策略写消纳、反调峰与偏差考核方向，须人工确认，禁止编造出清价。
