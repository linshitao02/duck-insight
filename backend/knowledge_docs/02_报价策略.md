# 报价策略要点

本文供 RAG 召回，服务日前电价预测之后的报价建议。数字必须来自模型评估指标与预测切片。

## 报价带怎么定

- 点预测（P50 / 回归均值）给出期望价格，不能单独当申报价。
- 用特征重要性判断价格对负荷、风光、小时、气温的敏感方向：负荷、残余负荷权重大，报价应随高峰负荷上移；风光权重大且预测偏高时，午间或大风时段不宜顶格。
- 建议申报覆盖「点预测 ± 验证误差」：可用 RMSE 或 MAE 作为带宽参考。例如 RMSE 约 25 元/MWh，高峰小时报价带至少覆盖该量级，避免刚好卡在点预测上被实时打穿。
- 高峰（早 8–10、晚 17–20）优先保证电量覆盖与价格上限余量；低谷与光伏大发时段报价更保守，防止高价报出却出清失败或偏差扩大。

## 气象驱动下的报价位移

- 热浪：气温与负荷特征上升，晚高峰上调报价带。
- 寒潮：取暖负荷抬升，若风电同时偏低，残余负荷走高，日前价易涨。
- 台风/大风切出：风电出力特征骤降，不要按「大风=低价」惯性报价。
- 强对流/阴雨：光伏午间低价窗口可能消失，避免按晴天曲线报低。

## 阻塞与断面

残余负荷高、外送不足时阻塞指数上升，分区价差扩大。报价不要假设全网统一出清；受阻方向避免按高价断面满送。

## 禁止项

- 不得根据知识库例行数字替换当日模型输出。
- 不得暗示系统已下单。报价策略需交易员确认。
