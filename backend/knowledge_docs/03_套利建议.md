# 套利建议要点

套利窗口来自价差，而不是来自话术。召回本文件时，必须对照【评估指标】和【预测切片】里的峰谷与日前-实时关系。

## 可观察的价差类型

- 峰谷价差：同一日前曲线上，晚高峰相对午间或后夜的价差。价差显著且阻塞不高时，才讨论时段平移或合约分解调整。
- 日前-实时价差：实时相对日前的偏差，与新能源预测误差、阵风切出、辐照骤变相关。模型若只训了日前价，不要编造实时价差数字。
- 分区价差：阻塞抬升时出现。没有阻塞特征就不要写断面套利。

## 窗口前提

1. 预测置信足够：验证集 RMSE/MAE 可接受，特征重要性稳定。
2. 气象情景不极端，或极端情景已在特征中显式出现（热浪、台风标记）。
3. 阻塞可控：高阻塞时峰谷套利可能被节点约束吃掉。
4. 中长期曲线已锁定大部分电量，现货只处理边际偏差，避免把中长期仓位当成日内超短投机。

## 操作表述

只给出「可观察窗口 + 前提 + 风险」，例如：晚高峰相对午间价差扩大且负荷特征主导时，可考虑在高峰保留买权/少卖，低谷相反。必须写需交易员确认。

## 禁止项

禁止推荐具体下单手数、禁止承诺无风险套利。
