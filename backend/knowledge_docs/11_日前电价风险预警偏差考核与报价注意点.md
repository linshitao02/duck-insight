# 日前电价预测的风险预警、偏差考核与报价注意点

检索关键词：风险预警、偏差考核、报价注意点、报价带、日前电价、日前出清、实时价格、峰谷价差、尖峰、阻塞、断面、分区价差、申报、报量报价、限价、中长期、偏差电费、需交易员确认、系统未下单。

依据公开资料整理：《电力现货市场基本规则（试行）》（国家发展改革委、国家能源局，2023）、《电力市场运行基本规则》（2024 年 7 月 1 日起施行），以及广东、山东、山西、浙江、甘肃、蒙西等现货试点省份结算细则中的通行表述。各省参数（限价、考核阈值、结算公式）差异很大，下文只给方向和判断口径，不得当作某省正式规则。本系统不下单。

## 本文服务谁

本文对应「日前电价（price_da）」预测链路的风险预警节点：模型输出的是日前价格曲线，本节点要写的是风险预警、偏差考核与报价注意点。数字只能来自模型评估指标与【预测切片】，本文只提供规则口径与检查清单。

**本文件不含任何数值。**没有价格数值、没有分位数、没有涨跌幅区间、没有阈值参数（示例中的 25 元/MWh 仅用于说明"带宽量级"这个概念，不是任何市场的数据）。如果报告里出现「知识库显示某分位数 / 知识库历史电价区间 / 预计上冲 X%」这类表述，一律属于编造，必须删除或改为定性描述。

## 电价的三个风险来源

1. **供需与峰谷**：日前价格由社会福利最大化的集中优化出清形成，负荷高峰、备用不足时段价格上冲，午间光伏大发、后夜低谷时段价格走低甚至触及下限。预测曲线若在尖峰小时明显偏低，报价带不足以覆盖，就会在有量时段亏钱。
2. **极端气象与新能源**：热浪抬升空调负荷与晚高峰价格；寒潮叠加大风偏低时残余负荷走高；台风切出使风电骤降、实时价格上冲；阴雨/强对流让午间低价窗口消失。这些都是「价格方向 × 误差方向」组合，报告要写清是价升险还是价跌险。
3. **阻塞与断面**：出清必须满足电网安全约束，断面阻塞时出现分区/节点价差。阻塞指数高时不能假设全网统一出清，受阻方向满送可能出清失败或产生阻塞电费。没有阻塞特征就不要写断面套利结论。

## 偏差考核与电价的关系

现货地区常见的结算结构（各省公式细节不同，分析时只引用系统给出的数字）：

- 中长期合约电量按合约价结算，锁定基础电量；
- 日前出清相对中长期的偏差（含中长期与日前曲线之差），按日前价格结算；
- 实际电量相对日前的偏差，按实时价格结算。

因此**电价预测误差会被两层放大**：日前曲线报歪 → 日前价结算偏差；实际与日前价差走反 → 实时价结算偏差。新能源场站还另有功率预测准确率/合格率的「两个细则」考核，与现货电能量偏差是两笔账，报告里写「偏差考核」时应写清是哪一层，不要把 RMSE 直接说成考核电费。

示意（各省不同）：实时偏差电费 ≈ Σ (实际电量 − 日前电量) × 实时价。新能源预测偏高而实际切出时，实时价往往同步上涨，考核与现货损失叠加。

## 报价注意点

- **点预测不等于申报价**。回归均值（P50）给出期望价格，必须用验证误差（RMSE / MAE）扩成报价带，例如 RMSE 约 25 元/MWh，高峰小时报价带至少覆盖该量级，避免刚好卡在点预测上被实时打穿。
- **顺着特征重要性调方向**。负荷、残余负荷权重大 → 报价随高峰负荷上移；风光权重大且预测偏高 → 午间或大风时段不宜顶格。
- **分时段差异化**。高峰（早 8–10、晚 17–20）优先保电量覆盖与价格上限余量；低谷与光伏大发时段更保守，防止高价报出却出清失败、反而扩大偏差。
- **注意限价与分段**。多数市场设申报价格上下限，并允许分段（多段量价对）申报；发电侧常见「报量报价」，部分用户侧「报量不报价」。报价段数、最小变动单位以当地规则为准。
- **申报颗粒度**。日前通常按小时或 15 分钟（96 点）申报，取决于本省结算颗粒度；颗粒度不匹配会导致曲线对不齐。
- **别按惯性报价**。台风/大风切出时不要按「大风 = 低价」惯性报价；强对流、阴雨时不要按晴天曲线报低。

## 预警触发（解释口径，阈值以系统告警为准）

- 价格点预测接近历史高分位且 RMSE 不小 → 报价带不足，考核敞口大。
- 热浪 + 负荷特征主导 → 晚高峰高价与向上偏差风险。
- 大风接近切出风速 → 日前偏低、实时偏高，价差与考核叠加。
- 辐照骤降 / 强对流 → 光伏午间出力不足，午间低价窗口消失。
- 阻塞代理升高 → 节点/分区价格可能与统一结算点分叉。

## 风控动作清单

1. 看模型评估：RMSE、MAE、R²，以及 Top 特征是否仍是负荷、气象、日历等合理项。
2. 看上游模型组件：负荷/风电/光伏预测区间是否异常（负值应裁剪为 0）。
3. 把考核风险写成「误差方向 × 价格方向」，不要只写「注意偏差」。
4. 给出可观察窗口 + 前提 + 风险即可，禁止推荐具体下单手数、禁止承诺无风险套利。
5. 升级为人工复核，不自动改申报；策略文本结尾必须写明需交易员确认，系统未下单。
