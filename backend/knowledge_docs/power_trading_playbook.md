# 电力交易分析知识库

本文件供 RAG 检索，支撑气象-负荷-出力-电价决策报告。数字结论仍以系统计算为准，不可编造未给出的量。

## 数据来源

- 实况：Open-Meteo ERA5 再分析（站点：上海负荷中心、江苏沿海风电、苏北徐州光伏）。
- 短期 1–3 天 / 中期至 16 天：ECMWF IFS 与 GFS 融合预报。
- 中长期 17–45 天：去年同期 ERA5 气候态平移，作为展望而非确定性预报。
- 电能量与价格：气象驱动的物理-统计模型（华东尺度容量假设），用于决策推演，不替代官方出清。

## 市场规则要点

- 日前：按小时申报；报价应覆盖预测不确定性，避免在阻塞断面满送。
- 实时：偏差考核与新能源预测误差相关；大风切出、辐照骤降会推升实时价格。
- 中长期合约：用于对冲极端天气带来的现货波动。
- 阻塞：残余负荷高、外送能力不足时分区价差扩大。

## 气象影响机制

- 热浪：气温 >33℃ 抬升空调负荷，晚高峰电价易涨。
- 寒潮：取暖负荷上升，风光若同时偏低则残余负荷走高。
- 台风/大风：风速过高风电机组切出，出力骤降。
- 强对流/阴雨：光伏出力受抑，午间低价时段可能消失。

## 策略原则

- 输出报价带、套利窗口、对冲建议，必须由交易员确认后执行。
- 不要自动下单。
- 解释时同时给出气象驱动与市场规则两条因果链。
