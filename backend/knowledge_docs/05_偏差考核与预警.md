# 偏差考核与风险预警

偏差考核把「预测不准」变成费用。报告应把模型误差和气象突变连到考核压力，而不是只报 RMSE。

## 偏差从哪来

- 日前相对中长期：负荷/报价与合约曲线不一致。
- 实时相对日前：超短期负荷、风光预测修正、机组与断面约束变化。
- 新能源功率预测考核：部分市场对短期预测准确率单独考核。
- 计划执行偏差：实时计划与实际出力/用电不一致。

示意（各省公式不同）：实时偏差电费 ≈ Σ (实际电量 − 日前电量) × 实时价。新能源预测偏高而实际切出时，实时价往往同步上涨，考核与现货损失叠加。

## 预警触发（解释口径，阈值以系统告警为准）

- 热浪 + 负荷特征主导：晚高峰高价与向上偏差风险。
- 大风接近切出风速：风电出力骤降，日前偏低、实时偏高。
- 辐照骤降/强对流：光伏午间出力不足。
- 电价点预测接近历史高分位且 RMSE 不小：报价带不足，考核敞口大。

## 风控动作清单

1. 看模型评估：RMSE、MAE、R²，以及 Top 特征是否仍合理。
2. 看上游模型组件：负荷/风电/光伏预测区间是否异常（含负值应裁剪为 0）。
3. 把考核风险写成「误差方向 × 价格方向」，不要只写「注意偏差」。
4. 升级为人工复核，不自动改申报。

## 数据注意

本平台当前电价链路为离线回放，没有实时出清接口。报告应写明离线，避免读者当成正式结算单。
