# 光伏出力预测、消纳与偏差考核

检索关键词：solar_mw、光伏出力、辐照、热浪、午间高峰、云遮蔽、消纳受阻、偏差考核。
依据公开资料整理：《电力现货市场基本规则（试行）》（国家发展改革委、国家能源局，2023）、光伏功率预测行业通行做法。本文为检索摘要，不替代正式规则；数字仍以本轮训练指标为准。本系统不下单。

## 物理机制

光伏有功出力主要随水平面短波辐射（GHI / radiation）变化，并受组件温度、云量和天气代码影响。晴空午间辐照最高，solar_mw 常出现日间单峰；阴雨、强对流、沙尘会把午间高峰削平甚至消失。

热浪情景下：气温升高一方面提高光伏组件温度、略降转换效率，另一方面往往伴随高辐照，净效果多为午间出力仍高。报告解释热浪对 solar_mw 的影响时，应同时写「辐照抬升」和「组件温升折损」，不要只写气温。

云遮蔽会使辐照在分钟–小时尺度骤降，超短期预测误差放大。模型若把 radiation、weather_code、is_convection、is_heat_wave 作为重要特征，符合物理直觉。

## 调度与现货含义

日前可靠性机组组合和现货出清会把可再生能源出力预测作为边界条件。光伏午间高发时，系统残余负荷下降，现货价格容易走低；若同时出现消纳受阻（断面阻塞、调峰空间不足），场站可能被限电，实际 solar_mw 低于资源可用出力。

交易解读口径：

- 午间高峰：关注是否「资源高发 + 价格走弱」；报价和中长期曲线不要在该时段顶格假设满发。
- 消纳受阻：特征重要性若突出阻塞/限电相关列，报告应提示限电不是模型失效，而是电网约束。
- 强对流/阴雨：光伏预测偏低，午间低价窗口可能消失，负荷侧购电成本上升。

## 偏差考核注意

新能源场站通常需向调度申报次日分时发电预测曲线（常见为 96 点、15 分钟分辨率）。实际出力相对日前计划或实时出清的偏差，可能进入现货偏差结算或功率预测考核。各省公式不同，分析时禁止编造考核金额。

常见风险方向：

1. 辐照预报偏高 → 日前 solar_mw 偏高 → 实发不足 → 需在实时补电，实时价若同步上涨则损失与考核叠加。
2. 云量突变未捕捉 → 超短期误差大，计划执行偏差扩大。
3. 模型输出小幅负值：无物理意义，决策与申报前应裁剪为 0。

## 对 LLM 报告的约束

解读光伏训练任务时：引用 RMSE / MAE / R² 和 Top 特征（尤其 radiation、temp_c、is_heat_wave）。策略只写「需调度/交易员确认」。离线回放不得写成正式结算单。
